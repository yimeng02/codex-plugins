# 更新记录

## 0.2.6 — 2026-10-30

- 新增 PreToolUse、PostToolUse 钩子，任务执行中在受支持的工具调用前后检查版本，有更新就准备最新全局记忆，不必等下一条用户消息。
- SessionStart(source="compact") 无条件重新加载，覆盖自动、手动压缩后的即时续行；用户消息及工具检查点继续按聊天、库版本和插件版本去重。
- 继续保留旧钩子定义、精确范围检索及原资料库；新增钩子需要单独审核信任。正在生成的模型请求或长命令在下一个受支持检查点接收更新。

详情：[0.2.6 更新说明](docs/RELEASE-0.2.6.md)。

## 0.2.5 — 2026-10-29

- 首次在 Codex 中使用时说明自然语言操作、网页管理、分类与批量管理、历史恢复、JSON 备份以及保存后的记忆刷新，再展示全局规则预览并询问选择。
- 用户随时询问使用方法、管理网页或地址时，通过 memory_status(include_help=true) 返回指南、可点击的实际网页链接与可核实的运行状态；已记录的全局规则选择不重复询问。
- 网页启动后登记当前资料库的实际端口，通过本机健康检查核对服务实例；跨 Windows/WSL 无法验证时如实标记，不将链接或启动命令当作服务已经运行。

详情：[0.2.5 更新说明](docs/RELEASE-0.2.5.md)。

## 0.2.4 — 2026-10-29

- 移除新增的插件标识匹配、网页匹配方式选择及对应 MCP/CLI 参数，统一按 scope 与 target 原值精确匹配。
- 清理编辑、Markdown 导出、工具说明与全局规则模板；原有全局记忆自动读取和更新刷新保留。
- 新导出格式为 schema_version=3，支持导入 1/2/3；兼容读取旧库和历史，不在打开时重写数据。

详情：[0.2.4 更新说明](docs/RELEASE-0.2.4.md)。

## 0.2.3 — 2026-10-29

- 修复 doctor.py 仍要求旧根清单而无法验收原生插件的问题，新增对实际原生分发副本的完整诊断测试。
- 更新个人市场的原生清单说明；自动加载行为沿用 0.2.2，启用前仍需审核具体钩子定义。

## 0.2.2 — 2026-10-29

- Codex 发行版改用原生 `.codex-plugin/plugin.json`，避免当前加载器跳过便携格式钩子。
- 修复全局 AGENTS 已加载但新会话未调用 memory_refresh 的漏读：新增 SessionStart 与 UserPromptSubmit 命令钩子，直接读取管理器资料库。
- 按聊天及资料库版本去重；启动/恢复/清空/压缩/派生时重建上下文，停用、删除或编辑后在下一条消息替换旧全局内容。
- memory_status 支持 session_id 查询准备记录，明确区分“已准备给宿主”与“模型已应用”。
- 限制自动上下文大小并明确标注遗漏；不自动注入其他范围正文，不写 AGENTS、不读内置记忆、不保存聊天正文。
- 安装包与本机安装器包含钩子及 Windows 命令；自定义数据目录与 MCP 保持一致，不自动批准钩子信任。
- 固定 CLI JSON 为 UTF-8，避免 Windows 默认代码页导致中文预览结果解码失败。

详情：[0.2.2 修复与启用说明](docs/RELEASE-0.2.2.md)。

## 0.2.1 — 2026-10-29

- 保留原目标精确匹配，新增独立的插件标识匹配方式，用户可在编辑器与导出中选择。
- 旧条目迁移为 exact，不改目标、版本和历史；插件标识另存 plugin_id，两种查询不混用。
- MCP 搜索、刷新、导出和 CLI publish 同步支持两种匹配方式。
- 完善全局读取规则，加入任务读取、匹配方式、记忆刷新、插件升级和规则模板更新要求；旧模板更新需重新预览和同意。
- Codex 首次提醒补全用途和更新步骤；已配置用户也能收到资料库更新提示，升级不重置原配置选择。

详情：[0.2.1 使用说明](docs/RELEASE-0.2.1.md)。

## 0.2.0 — 2026-10-29

- 插件范围新增本机插件标识选择；显示名称与实际 ID 分开，旧目标保留并支持手动标识。
- 网页显示库版本与最近一次插件读取版本；更新后提醒到 Codex 使用 memory_refresh，复制指令不会误报已读取。
- 首次在 Codex 聊天实际使用时询问是否将指定三行规则加入全局 AGENTS；先预览、明确同意后才写入，保留原文并备份，记录加入/暂不加入/稍后选择。网页不显示首次配置询问。
- 新增 memory_status、memory_plugins、memory_refresh、memory_setup；操作元数据不改变条目版本或库 revision。

详情：[0.2.0 使用说明](docs/RELEASE-0.2.0.md)。
