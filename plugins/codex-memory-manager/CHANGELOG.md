# 更新记录

## 0.2.1 — 2026-10-29

- 保留原目标精确匹配，新增独立的插件标识匹配方式，用户可在编辑器与导出中选择。
- 旧条目迁移为 exact，不改目标、版本和历史；插件标识另存 plugin_id，两种查询不混用。
- MCP 搜索、刷新、导出和 CLI publish 同步支持两种匹配方式。
- 完善全局读取规则，加入任务读取、匹配方式、记忆刷新、插件升级和规则模板更新要求；旧模板更新需重新预览和同意。
- Codex 首次提醒补全用途和更新步骤；已配置用户也能收到资料库更新提示，升级不重置原配置选择。

详情：[0.2.1 使用说明](docs/RELEASE-0.2.1.md)。

## 0.2.0 — 2026-10-29

- 插件范围新增本机插件标识选择；显示名称与实际 ID 分开，旧目标保留并支持手动标识。
- 网页显示库版本与最近一次插件读取版本；更新后提醒到 Codex 使用 memory_refresh，复制指令不会误报已读取。
- 首次在 Codex 聊天实际使用时询问是否将指定三行规则加入全局 AGENTS；先预览、明确同意后才写入，保留原文并备份，记录加入/暂不加入/稍后选择。网页不显示首次配置询问。
- 新增 memory_status、memory_plugins、memory_refresh、memory_setup；操作元数据不改变条目版本或库 revision。

详情：[0.2.0 使用说明](docs/RELEASE-0.2.0.md)。

## 0.1.5 — 2026-10-29

- 修正 Windows 测试中短路径别名与路径分隔符的断言，保留真实宿主的占位符展开行为。
- 原数据目录可从当前 CODEX_HOME 或标准插件安装缓存位置推导，避免 MCP 子进程未继承自定义环境时打开另一套默认库。显式 CODEX_MEMORY_HOME 仍最高优先级。
- 本插件迁入 GitHub 的 Yimeng02 市场；保留独立原记忆库及其内容。

## 0.1.4 — 2026-10-29

- 提供 GitHub 个人市场来源 `yimeng02/codex-plugins`，沿用仓库既有的 `yimeng02` 市场和 `plugins/` 布局；本机安装器仍保留独立 `personal-memory-tools` 入口。
- 修复 portable MCP `command` 使用 Python 绝对路径的格式错误；本机安装器改用裸命令和子进程 PATH，旧格式独立保留绝对运行时。
- 在真实握手前检查 Codex portable MCP 配置规则，拦截旧自检会漏报的 command、cwd、保留环境变量和字段错误。
- WSL 当前用户默认库不存在时，可复用 CODEX_HOME 父目录中已有的记忆库；明确指定的数据目录仍优先。
- 统一版本说明，新增个人市场安装与更新说明及跨平台 CI。安装、独立 MCP 自检和桌面会话工具加载分别报告。

详情见 [GitHub 市场说明](docs/GITHUB-MARKETPLACE.md) 和 [客户端加载说明](docs/CLIENT_LOADING.md)。
