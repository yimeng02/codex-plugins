# 0.2.3：原生插件诊断兼容

包含 [0.2.2 的新聊天自动读取修复](RELEASE-0.2.2.md)。每个新聊天在首轮回复前通过已审核钩子准备全局记忆；资料库更新后在下一条消息刷新。

本版修复诊断脚本仍要求旧根 plugin.json 的问题。只有原生 `.codex-plugin/plugin.json` 的发行包也能完成技能检查、两种 MCP 配置握手和只读调用。

从 Yimeng02 个人市场更新后，完全退出并重启 Codex，按提示审核并信任 SessionStart 与 UserPromptSubmit。原记忆库和全局 AGENTS 保留。安装登记不代表钩子已受信任，准备记录也不代表模型已经遵循。

验证：Linux 140 项测试通过；Windows Python 3.13 的适用测试通过，5 项平台差异跳过。实际原生安装缓存的技能检查、两种 MCP 握手与只读调用通过；最终版本在隔离 Codex 宿主的首个模型请求中注入了全局记忆。测试钩子信任只写入隔离配置，实际用户钩子仍需审核。
