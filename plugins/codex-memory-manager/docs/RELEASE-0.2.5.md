# 0.2.5 使用引导与网页入口

首次在 Codex 聊天中实际使用本插件时，会先介绍怎样通过自然语言查看、搜索、保存、修改和分类记忆，怎样批量启停、移动、回收和恢复，以及怎样查看历史、导入导出 JSON。也会提供本机管理网页链接、网页操作步骤，以及保存后如何在聊天中重新读取记忆。

尚未选择全局读取规则的用户，查看引导后再预览实际生效的 AGENTS 文件与规则，明确同意后才写入。已配置、暂不加入或稍后处理的用户不会因升级再次被询问；主动询问使用方法时仍能获得完整帮助。

## 随时询问用法或网页

在 Codex 中可以直接说：

- “memory-manager 怎么使用，如何管理记忆？”
- “给我记忆管理网页链接。”
- “使用 memory-manager 更新本聊天的记忆。”

前两类请求调用 `memory_status(include_help=true)`。回复使用本次 `web_manager.url` 作为可点击链接，并如实说明运行状态；不只给启动命令。未找到运行记录时返回默认地址 `http://127.0.0.1:8765/`，同时标注尚未验证服务已启动。网页使用其他端口时，按当前资料库的运行记录返回实际地址。

新版本网页进程会在资料库旁写入小型运行记录，健康检查仅访问本机回环地址，并核对服务与实例。运行记录不包含记忆正文，也不改变条目或资料库版本。Windows 页面与 WSL 工具无法互访回环服务时，保留已知地址并标注未验证，在启动页面的本机浏览器打开。

## 更新

从已配置的 Yimeng02 个人市场更新插件；使用 CLI 时依次执行：

```sh
codex plugin marketplace upgrade yimeng02
codex plugin add codex-memory-manager@yimeng02
```

完全退出并重启 Codex，在本地新聊天使用更新后的工具。正在运行的管理页面进程也需重启，才能登记实际地址与提供健康检查。此次升级保留原资料库、全局规则及钩子定义；记忆内容更新仍通过 `memory_refresh` 重新读取，无需重装插件。
