# 更新日志

本项目使用语义化版本号。

## [1.2.0] - 2026-08-13

### 新增

- 首次配置契约：必须先向用户收集禅道地址、成员账号、隐藏输入的密码和明确授权的项目 ID；支持可选的外层 HTTP Basic 与源码映射。
- 每次成功写入返回 `ui_verification`，要求刷新、核对并展示已登录的真实禅道结果页截图。
- 完整的公开市场安装、更新、首次配置、日常使用、安全边界和故障排查文档。

### 改进

- 写入后清理身份、项目和产品缓存，并绕过缓存执行权威回读；截图失败不会诱发重复写入。
- 配置命令不再接受空密码，禅道地址和项目白名单均为显式必填参数。

## [1.1.0] - 2026-08-13

### 新增

- 开发者成员默认每日 07:00 新增 Bug 扫描规范。
- 账号私有的持久扫描游标、待处理队列和失败重试状态。
- 包含完整 Bug 证据、根因、方案、风险与验证计划的 JSON/Markdown 跨会话解决方案包。

### 安全

- 定时分析不会修改源码，也不会准备或执行任何禅道写入。

## [1.0.0] - 2026-08-12

### 新增

- 按禅道成员分组和实时权限动态生成 MCP 工具。
- 项目白名单、凭据外置存储、写入预览与一次性确认令牌。
- Bug、需求、任务、产品、项目与执行的权限感知读写流程。
- 写入后缓存失效与权威回读验证。
